# Data Analysis Portfolio

Exploratory data analysis projects in Python (with Power BI dashboards) across
retail, e-commerce, healthcare and finance. Each project loads and cleans a
dataset, explores it with visualisations, and answers business questions.

## Projects

| Project | Domain | Focus |
|---------|--------|-------|
| [E-Commerce](ecommerce) | E-commerce | Sales trends, product & country concentration, returns |
| [Customer Churn](customer-churn) | Banking | Churn drivers by segment, retention recommendations |
| [Healthcare Costs](healthcare) | Healthcare | Drivers of insurance charges (smoking, age, BMI) |
| [Retail Sales](retail-sales) | Retail | Sales performance by product, category and demographics |
| [Financial Transactions](synthetic-finance) | Finance | Income, loans, savings and credit-score patterns |

## Skills demonstrated
- Data loading, cleaning and validation (nulls, duplicates, outliers)
- Exploratory data analysis and visualisation
- Answering business questions and turning them into recommendations
- Pairing Python analysis with Power BI dashboards

## Tools
Python, pandas, matplotlib, seaborn, Jupyter, Power BI.
