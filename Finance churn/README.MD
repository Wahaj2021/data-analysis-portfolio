# Customer Churn Analysis (Banking)

Exploratory analysis of bank customer data in Python to measure churn and
identify high-risk segments for retention.

## Key findings
- Establishes a baseline churn rate, then breaks it down by segment.
- Churn varies across geography, activity status, age group and product holding.
- Inactive customers and certain demographic/product segments churn at notably
  higher rates.

## Recommendations
- Prioritise retention for high-churn geographies and inactive customers.
- Improve early-lifecycle engagement for low-activity customers.
- Use targeted offers and cross-sell to reduce churn in low-product segments.

## Tools
Python, pandas, matplotlib, seaborn. Paired with a Power BI dashboard.
